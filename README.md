# 이등병 생존 가이드

소대원의 **계급(선임 순서)**, **근무 편성**, **휴가·외박·외출 일정**을 한눈에 보는 모바일 앱입니다.
설치형 앱(PWA)이고, 완전히 오프라인으로 동작합니다.

- 서버 없음 · 로그인 없음 · 통신 없음
- 모든 데이터는 **내 폰 안에만** 저장됩니다 (localStorage)
- 비행기 모드, 데이터 차단 상태에서도 그대로 실행됩니다

---

## 폰에 설치하기

1. 브라우저에서 배포된 주소를 엽니다. (아래 *배포* 참고)
2. **안드로이드(Chrome)**: 우측 상단 ⋮ → **홈 화면에 추가** → **설치**
3. **아이폰(Safari)**: 하단 공유 버튼 → **홈 화면에 추가**
4. 홈 화면 아이콘으로 실행하면 주소창 없는 앱 화면으로 열립니다.

한 번 열어두면 파일이 캐시되어, 이후에는 인터넷 없이도 실행됩니다.

## 배포 (GitHub Pages, 폰에서 설정 가능)

이 저장소에는 Pages 배포 워크플로가 들어 있습니다. 한 번만 켜주면 됩니다.

1. 폰 브라우저에서 이 저장소 → **Settings** → **Pages**
2. **Build and deployment › Source** 를 **GitHub Actions** 로 변경
3. **Actions** 탭에서 `Deploy to GitHub Pages` 실행이 끝나면 주소가 나옵니다
   (보통 `https://<사용자명>.github.io/e1-survival-guide/`)

> 서비스 워커(오프라인 캐시)는 HTTPS에서만 등록됩니다. GitHub Pages는 HTTPS라 그대로 동작합니다.

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| **오늘** | **오늘 · D-1 · D-2 세 장**으로 넘겨 보는 화면. 지금 근무 중인 사람, 내 근무, 그날 근무 편성, 그날 부재자, 소대 현황판, 그날 상태 메모 |
| **요약** | 점호·식사·불침번 **보고 문구를 자동 작성**하는 한장 요약 (아래 참고) |
| **근무** | 날짜를 넘기며 근무별·시간대별로 인원 배정. 부재자 경고, 최근 14일 근무 횟수 표시 |
| **소대원** | `명단` = 간부/병 그룹, 계급·입대일 기준 **선임 순** 정렬, 전역 D-day / `사로표` = 생활관별 2열×6행 사로표 |
| **일정** | 월 달력에서 부재자·근무 편성 여부 확인, 휴가·외박·외출·파견 등록 |
| **설정** | 내 정보, 생활관, 점호·보고 시각, 배식 순번, 근무 종류·시간대, 백업·복원 |

### 오늘 · D-1 · D-2 (같은 화면 세 장)

`오늘` 탭은 **똑같이 동작하는 화면 세 장**입니다. 왼쪽 위 제목이 `오늘` → `D-1` → `D-2` 로 바뀌고,
그 아래 3칸 전환 버튼(날짜·요일 표시)으로 넘깁니다. **하단 탭은 `오늘` 한 칸뿐**이고,
탭을 누르면 항상 `오늘` 화면으로 돌아옵니다.

세 장 모두 그날 기준으로 근무 편성 · 부재자 · 소대 현황판 · 내 근무 · 상태 메모를 보여줍니다.
(`지금 근무 중` 카드만 오늘 화면에서 뜻이 있어 오늘에만 나옵니다.)

각 화면 맨 위에 그날 **상태 · 특이사항**을 미리 적어둘 수 있습니다.
날짜에 묶여 저장되므로 **하루가 지나면 D-1 에 적어둔 내용이 그대로 `오늘` 자리로 올라옵니다.**
앱은 1분마다, 그리고 화면으로 돌아올 때마다 다시 그리므로 자정에 켜둬도 알아서 바뀝니다.
전환 버튼의 초록 점은 그 날짜에 메모가 있다는 표시입니다.

3일보다 먼 날짜의 메모는 **일정** 탭에서 날짜를 눌러 씁니다.

### 생활관 · 사로표

소대를 생활관 단위로 나눠 관리합니다. 소대원마다 생활관과 사로(1~11)를 지정하면
**소대원 → 사로표** 에서 생활관별 배치를 한눈에 봅니다.

- 2열 × 6행 = 12칸, 왼쪽 1~6사로 · 오른쪽 7~11사로 (12번째 칸은 사용하지 않음)
- 칸을 누르면 그 사로에 누구를 넣을지 고릅니다. 다른 생활관 사람도 바로 끌어올 수 있고,
  이미 누가 있던 사로면 그 사람의 사로가 자동으로 비워집니다
- 칸 아래 색 띠 = 초록 근무 중 · 파랑 오늘 근무 · 노랑 부재

### 한장 요약 (인원보고 문구 자동 작성)

날짜와 범위(소대 전체 / 특정 생활관)를 고르면 그날 보고할 문구가 전부 만들어집니다.
숫자는 명단·근무 편성·휴가 기록에서 자동으로 계산되고, **문구 복사** 를 누르면 그대로 붙여넣을 수 있습니다.

| 항목 | 문구에 들어가는 것 |
|---|---|
| 아침점호 | 총원, 휴가, 파견, 근무(근무별 내역 + 근무취침), 현재원 |
| 아침·점심·저녁 식사집합 | 총원, 휴가, 파견, 근무, 선식, 현재원 + `n배식 시각` |
| 생활관 인원보고 | 생활관별 총원·휴가·파견·근무·현재원 |
| 저녁점호집합 | 아침점호와 동일 |
| 불침번 보고 | 생활관 단위로 총원, 휴가, 파견, 근무, 연등, 현재원, 생활관 온도, 특이사항 |

계산 규칙:

- `현재원 = 총원 − 휴가 − 파견 − 근무` (식사집합은 선식도, 불침번 보고는 연등도 뺍니다)
- **휴가**는 휴가·외박·외출·병가·기타, **파견**은 부재 종류를 `파견`으로 등록한 사람입니다
- **근무**는 그 보고 시각에 실제로 근무 중인 사람입니다. 자정을 넘는 야간 근무도 정확히 잡고,
  `당직`처럼 일 단위 근무는 하루 종일로 셉니다. 한 사람이 두 번 세어지는 일은 없습니다
- 번개조처럼 인원보고에서 빼야 하는 근무는 **설정 → 근무 종류 → 인원보고** 에서 집계를 끕니다
- 선식 · 근무취침 · 연등은 자동으로 알 수 없으니 각 카드의 버튼으로 그날 인원을 지정합니다
- 불침번 **특이사항** 에는 앞으로 8시간 내 투입되는 근무자의 기상 안내가 자동으로 붙습니다
  (`불침번 2번초 김이병 23:20 기상 (23:30 투입)`). 기상 예고 시간은 설정에서 바꿉니다

### 배식 순번

`설정 → 배식 순번` 에서 끼니별 1배식 시각(기본 아침 08:00 · 점심 11:30 · 저녁 17:30),
배식 간격(기본 10분), 총 배식 수(기본 4), 이번 주 우리 순번을 정합니다.
**주마다 순번 자동 회전** 을 켜두면 매주 한 칸씩 밀려서 (4배식 → 다음 주 1배식) 직접 고칠 필요가 없습니다.

### 기본 근무 종류

`불침번(5번초)`, `CCTV(6교대)`, `위병소(6교대)`, `번개조(일 단위, 인원보고 제외)`, `당직(당직사관/당직병)`

시간대·필요 인원·이름은 **설정 → 근무 종류**에서 부대 실정에 맞게 전부 수정할 수 있고,
새 근무 종류도 추가할 수 있습니다.

## 데이터 관리

- **백업**: 설정 → *백업 복사* → 나온 문자열을 메모장이나 본인에게 보내는 메시지에 저장
- **복원**: 설정 → *복원* → 백업 문자열 붙여넣기
- 브라우저 데이터를 지우거나 앱을 삭제하면 데이터도 사라집니다. 폰을 바꾸기 전에 백업하세요.

> 실명·부대 정보는 저장소나 코드에 들어가지 않습니다. 앱에서 입력한 내용은 폰에만 남습니다.

## 개발

빌드 도구, 패키지 매니저, 의존성이 전혀 없습니다. 정적 파일뿐입니다.

```
index.html               앱 껍데기
app.css                  스타일 (모바일 우선, 다크)
app.js                   전체 로직 (바닐라 JS, 단일 파일)
sw.js                    오프라인 캐시 서비스 워커
manifest.webmanifest     PWA 매니페스트
icons/                   앱 아이콘 (192/512/maskable)
```

로컬에서 보려면 정적 서버 하나만 있으면 됩니다.

```sh
python3 -m http.server 8080
# http://localhost:8080
```

`app.css` / `app.js` 를 수정했으면 `sw.js` 상단의 `CACHE` 버전 문자열을 올려야
설치된 앱에 새 버전이 반영됩니다.
